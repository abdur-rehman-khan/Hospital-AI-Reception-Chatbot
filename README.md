# 🏥 Hospital AI Reception Chatbot (Static)

**Day 5 Mini Project** — AI-Assisted Hospital Workflow  
Built with plain HTML + JavaScript + Claude API (no Gradio, no Python)

## How to Deploy on Hugging Face

1. Go to **huggingface.co/spaces**
2. Click **"Create new Space"**
3. Set SDK to **"Static"**
4. Upload `index.html` and this `README.md`
5. Live instantly — no build step needed!

## Human-AI Balance

| Step | Who |
|------|-----|
| Symptom collection | 🤖 AI |
| Urgency scoring 1–5 | 🤖 AI |
| Wait time estimate | 🤖 AI |
| FAQ & directions | 🤖 AI |
| Critical alert (Level 4–5) | 🤖 AI triggers → 👨‍⚕️ Human responds |
| Clinical examination | 👨‍⚕️ Human Doctor only |
| Diagnosis & treatment | 👨‍⚕️ Human Doctor only |

## Tech
- **SDK:** Static (pure HTML/CSS/JS)
- **AI:** Claude Sonnet via Anthropic API
- **No dependencies, no build, no Python**
